# Terminal demo

Install VHS and mdmore, then render from this directory:

```sh
brew install vhs
vhs mdmore.tape
```

The tape runs `mdmore` from `PATH` and writes `mdmore.gif` and `mdmore.mp4`.
It shows paging, tables,
search, code blocks, backward navigation, and help.
